# LUMICARD

## AIM

To design and fabricate a creative handmade LED greeting card to produce an attractive glowing effect.

## MATERIALS REQUIRED

* Origami paper  
* Coin cell battery-3V  
* LED  
* Craft paper  
* Glue  
* Scissor  
* Pencil and sketch pen

&nbsp;

## PROCEDURE

1. Take a colour  paper and prepare a greeting card base.  
2. Place the LED inside or on the decorative portion of the card to create a glowing effect.  
3. Connect the LED to the coin cell battery using  an aluminum foil sheet.  
4. Make a pink flower using origami paper and attach it to the card.  
5. Place the LED  inside the flower.  
6. Check whether the LED is glowing properly.

&nbsp;

## OBSERVATION

* The greeting card combines paper and basic electronic components.  
* The LED provides an attractive lighting effect inside the flower.  
* The battery supplies electrical energy to the LED.  
* &nbsp;The project develops creative ,paper craft skills and basic electronic components knowledge.&nbsp;
